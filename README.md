# 同時配布エリア選択（情報誌くれよん）

地図の区画をクリック／タップすると、配布可能部数と配布料金（税別）を自動で計算するページ。
エリア: **西区・北区**（74区画）／**稲沢**（65区画：A〜H 50・祖父江 10・平和 5）

## 使い方
- 上の「西区・北区／稲沢」でエリアを切り替える（エリアごとの選択は切り替えても残る）
- 稲沢は地図が3枚（稲沢 A〜H／祖父江／平和）。地図の上のボタンで切り替え、ボタンの数字はその地図で選んでいる区画の数
- 地図の区画、または下の一覧のチェックで選ぶ（もう一度押すと解除）
- チラシサイズ・折加工・挟み込みを選ぶと料金が変わる
- **部数の調整（端数合わせ）** … 選んだ区画の中から1つを選び、減らす部数を入れる（例: 合計30,123部 → 1区画で123部減らして30,000部）。「千部単位にそろえる」で端数を自動で入れる（押すたびに前の調整をリセットして計算し直す。選んでいる区画で引けなければ部数がいちばん多い区画から）。単価の段階は調整後の部数で決まる
- 「選択内容をコピー」… 選んだ区画・部数・料金を文章でコピー（メールやLINEに貼れる）
- 「このURLを共有」… 選択状態つきのURLをコピー（開くと同じ選択になる）

## ファイル
- `index.html` / `style.css` / `app.js` … 配布マップ版の画面（エリアの数に関係なく動く）
- `price.js` … 料金の計算（配布マップ版と地図版で共通）
- `extras.js` … 部数の調整（配布マップ版と地図版で共通）
- `data/seihoku.js` / `data/inazawa.js` … 配布マップ版の区画（番号・地名・可能部数・配布マップ上の形）
- `images/map-*.jpg` … 配布マップ（PDFを画像にしたもの）

## 部数・料金を変えるとき
- **部数・地名** … `data/○○.js`（地図版は `data/○○-geo.js` も）の `copies`（部数）・`name`（地名）を書き換える
- **単価** … `price.js` の `SIZE_PRICE`（サイズごとに [5,000部未満, 1万部未満, 3万部未満, 3万部以上]）、`foldPrice`（折加工）、`insertPrice`（挟み込み）

計算は「同時配布エリア選択シート_2026.6.30」と同じ: 配布料金(税別) = 合計部数（調整後） × (サイズ単価 + 折加工 + 挟み込み)。

## 地図版（試作）map.html
- 実際の地図（国土地理院の淡色地図）の上で区画を選べる版。西区・北区と稲沢（`data/inazawa-geo.js`）
- 区画の形（`data/seihoku-geo.js`）は、国勢調査の町丁目境界（e-Stat・令和2年）を組み合わせ、町丁目をまたぐ所だけ配布マップの線で切り分けて作った。境目は実際と数十メートルずれることがある
- 住所・町名で地図を移動できる（国土地理院の住所検索）
- **円で選ぶ** … 地図の中心にピンを置き、半径（0.5〜5km）の円に入る区画をまとめて追加できる。ピンはドラッグで動かせる。区画の面積の半分以上が円に入っていれば対象（map-app.js の CIRCLE_SHARE）
- 背景は国土地理院の地図で決定（2026-10-22）。地図を扱う部分は `map-adapter.js` にまとめてある
- **一宮**（`data/ichinomiya-geo.js`・192区画・155,412部）… 配布マップ6枚（木曽川・今伊勢・大和・千秋・奥町・上祖父江の各周辺）から作成。地図で2か所に分かれている浅井10と A17（東五城2）は1区画にまとめた。木曽川沿いの河川敷など、配布マップで区画の外になっている所は選べない
- **津島・大治・愛西・蟹江**（`data/tsushima-geo.js`・174区画・58,097部）… 各市町の全体地図4枚から作成。境界線がきれいな地図なので、町丁目は使わず配布マップの区画の形をそのまま位置合わせした。愛西・蟹江は地図で黄色の区画だけが配布対象
- エリアの並び: 一宮／稲沢／江南・大口・扶桑・岩倉／北名古屋／清須・あま／津島・大治・愛西・蟹江／西区・北区（2026-10-23）。共有URLにはいつも area= を入れる（area の無い古いURLは西区・北区として開く）

## 保存した選択・申込書（地図版）
- 「選択内容をコピー」を押すと、右側の「保存した選択」に残る（このブラウザの中だけ・18件まで。古いものから消える）。メモ欄にクライアント名を入れておける
- 左のチェックで選んで「選んだ ○件を削除」でまとめて消せる（「すべて選ぶ」あり・削除前に確認）。1件だけなら × でも消せる
- 「開く」でその選択に戻る。「申込書DL」は**スタッフ用**（パスワード）で、配布会社向けの申込書PDF（A3 2枚）を作る: 1枚目＝エリア別配布部数＋注文書、2枚目＝選んだ区画の地図
- 配布会社への単価・配布会社名は `data/staff.enc.js` に暗号化して入れてある（ページのソースを見ても読めない）。変えるときは社内の make-staff-config.js を書き換えて、パスワードを付けて作り直す
