# 同時配布エリア選択（情報誌くれよん）

地図の区画をクリック／タップすると、配布可能部数と配布料金（税別）を自動で計算するページ。
今は **西区・北区** のみ。

## 使い方
- 地図の区画、または下の一覧のチェックで選ぶ（もう一度押すと解除）
- チラシサイズ・折加工・挟み込みを選ぶと料金が変わる
- 「選択内容をコピー」… 選んだ区画・部数・料金を文章でコピー（メールやLINEに貼れる）
- 「このURLを共有」… 選択状態つきのURLをコピー（開くと同じ選択になる）

## ファイル
- `index.html` / `style.css` / `app.js` … 画面と計算
- `data/seihoku.js` … 区画の番号・地名・可能部数・地図上の形
- `images/map-seihoku.jpg` … 地図（西北配布マップ.pdf を画像にしたもの）

## 部数・料金を変えるとき
- **部数・地名** … `data/seihoku.js` の `copies`（部数）・`name`（地名）を書き換える
- **単価** … `app.js` の `SIZE_PRICE`（サイズごとに [5,000部未満, 1万部未満, 3万部未満, 3万部以上]）、`foldPrice`（折加工）、`insertPrice`（挟み込み）

計算は「同時配布エリア選択シート_2026.6.30」と同じ: 配布料金(税別) = 合計部数 × (サイズ単価 + 折加工 + 挟み込み)。
