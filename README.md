# 同時配布エリア選択（情報誌くれよん）

地図の区画をクリック／タップすると、配布可能部数と配布料金（税別）を自動で計算するページ。
エリア: **西区・北区**（74区画）／**稲沢**（65区画：A〜H 50・祖父江 10・平和 5）

## 使い方
- 上の「西区・北区／稲沢」でエリアを切り替える（エリアごとの選択は切り替えても残る）
- 稲沢は地図が3枚（稲沢 A〜H／祖父江／平和）。地図の上のボタンで切り替え、ボタンの数字はその地図で選んでいる区画の数
- 地図の区画、または下の一覧のチェックで選ぶ（もう一度押すと解除）
- チラシサイズ・折加工・挟み込みを選ぶと料金が変わる
- **部数の調整（端数合わせ）** … 選んだ区画の中から1つを選び、減らす部数を入れる（例: 合計30,123部 → 1区画で123部減らして30,000部）。「千部単位にそろえる」で端数を自動で入れる（区画を選んでいなければ部数がいちばん多い区画から）。単価の段階は調整後の部数で決まる
- **代理店** … チェックすると売値に1部＋1.0円
- 「選択内容をコピー」… 選んだ区画・部数・料金を文章でコピー（メールやLINEに貼れる）
- 「このURLを共有」… 選択状態つきのURLをコピー（開くと同じ選択になる）

## ファイル
- `index.html` / `style.css` / `app.js` … 配布マップ版の画面（エリアの数に関係なく動く）
- `price.js` … 料金の計算（配布マップ版と地図版で共通）
- `extras.js` … 部数の調整と代理店（配布マップ版と地図版で共通）
- `data/seihoku.js` / `data/inazawa.js` … 配布マップ版の区画（番号・地名・可能部数・配布マップ上の形）
- `images/map-*.jpg` … 配布マップ（PDFを画像にしたもの）

## 部数・料金を変えるとき
- **部数・地名** … `data/○○.js`（地図版は `data/○○-geo.js` も）の `copies`（部数）・`name`（地名）を書き換える
- **単価** … `price.js` の `SIZE_PRICE`（サイズごとに [5,000部未満, 1万部未満, 3万部未満, 3万部以上]）、`foldPrice`（折加工）、`insertPrice`（挟み込み）、`agentPrice`（代理店）

計算は「同時配布エリア選択シート_2026.6.30」と同じ: 配布料金(税別) = 合計部数 × (サイズ単価 + 折加工 + 挟み込み)。

## 地図版（試作）map.html
- 実際の地図（国土地理院の淡色地図）の上で区画を選べる版。今は西区・北区のみ
- 区画の形（`data/seihoku-geo.js`）は、国勢調査の町丁目境界（e-Stat・令和2年）を組み合わせ、町丁目をまたぐ所だけ配布マップの線で切り分けて作った。境目は実際と数十メートルずれることがある
- 住所・町名で地図を移動できる（国土地理院の住所検索）
- **背景を Google マップにするとき**: `map-adapter.js` だけを Google Maps 版に書き換え、`map.html` の Leaflet の読み込みを Google Maps の読み込み（APIキー付き）に替える。区画データと計算（`map-app.js`・`price.js`）はそのまま使える
